# Mind Map Mastery English

Quero criar uma landing page PREMIUM, moderna, responsiva e altamente persuasiva para um produto digital de inglês.

IMPORTANTE:

Não copie visualmente nenhuma página existente.

Não use preto + amarelo.

Quero uma identidade completamente nova, mais profissional, moderna e sofisticada.

PRODUTO:

+400 MAPAS MENTAIS PARA APRENDER E REVISAR INGLÊS

O produto é uma biblioteca digital com mais de 400 mapas mentais de inglês, organizados para facilitar aprendizado, consulta e revisão.

OBJETIVO DA PÁGINA:

Converter tráfego frio vindo de Meta Ads em compras de low ticket.

A página precisa ser:

- profissional

- moderna

- rápida

- visual

- fácil de entender

- curta o suficiente para não cansar

- muito boa no mobile

- com forte demonstração do produto

- sem aparência de template genérico de infoproduto

IDENTIDADE VISUAL:

Criar uma identidade própria.

Paleta sugerida:

- azul-marinho profundo

- azul royal moderno

- branco/off-white

- azul muito claro para fundos

- pequenos detalhes em coral ou laranja suave para destaque

Não usar fundo preto predominante.

Não usar amarelo como cor principal.

A página deve transmitir:

EDUCAÇÃO + ORGANIZAÇÃO + FACILIDADE + MODERNIDADE + CONFIANÇA.

Tipografia moderna, muito legível e profissional.

2. HERO SECTION

-------------------------------------

Essa é a parte mais importante.

Criar um hero extremamente profissional.

“INGLÊS DE UM JEITO MAIS VISUAL”

Headline grande:

“+400 MAPAS MENTAIS PARA APRENDER E REVISAR INGLÊS”

Subheadline:

“Gramática, vocabulário, expressões, phrasal verbs e conteúdos essenciais organizados de forma visual para você estudar sem se perder em explicações enormes.”

Adicionar benefícios rápidos em pequenos pills/cards:

✓ Do básico ao avançado

✓ Conteúdo visual e organizado

✓ Acesse pelo celular, tablet ou computador

✓ Ideal para aprender e revisar

Adicionar CTA principal grande:

“QUERO ACESSAR OS MAPAS”

Abaixo do CTA:

“Acesso digital • Liberação após a compra”

Na lateral ou abaixo, criar um mockup premium mostrando vários mapas mentais em notebook, tablet e celular.

Os mapas devem parecer materiais educacionais reais e visualmente ricos.

-------------------------------------

3. SEÇÃO PROBLEMA

-------------------------------------

Headline:

“Estudar inglês não precisa significar encarar páginas e páginas de conteúdo.”

Criar comparação visual.

Lado esquerdo:

“JEITO TRADICIONAL”

- textos enormes

- conteúdo espalhado

- dificuldade para revisar

- não saber o que realmente importa

Lado direito:

“COM MAPAS MENTAIS”

- informações resumidas

- conteúdo organizado

- exemplos visuais

- consulta rápida

- revisão mais prática

Usar visual moderno, sem exagerar nos textos.

-------------------------------------

4. SEÇÃO PRINCIPAL — MATERIAL POR DENTRO

-------------------------------------

Essa seção é ESSENCIAL.

Título pequeno:

“VEJA ANTES DE COMPRAR”

Headline:

“Veja como o material é por dentro”

Subheadline:

“Mapas organizados e ilustrados para tornar seus estudos e revisões muito mais simples.”

Criar um CARROSSEL HORIZONTAL PREMIUM.

O carrossel deve:

- deslizar automaticamente devagar

- permitir arrastar com mouse/dedo

- ter setas discretas

- funcionar perfeitamente no celular

- pausar quando o usuário interagir

- ter efeito visual suave

Mostrar entre 5 e 8 cards visíveis ao longo da rolagem.

Cada card deve possuir um exemplo diferente de mapa mental.

Exemplos de temas:

- Verb To Be

- Simple Present

- Simple Past

- Much x Many

- Was x Were

- Professions

- Phrasal Verbs

- Prepositions

- Travel English

- Everyday Expressions

IMPORTANTE:

Essas imagens serão substituídas depois pelas imagens reais do produto.

Criar placeholders profissionais para elas.

Adicionar abaixo:

“São mais de 400 mapas organizados em diferentes temas e níveis.”

CTA:

“QUERO TER ACESSO COMPLETO”

-------------------------------------

5. BIBLIOTECA ORGANIZADA

-------------------------------------

Headline:

“Não são mapas soltos. É uma biblioteca organizada de inglês.”

Criar cards modernos para categorias:

Tempos verbais, preposições, pronomes, estruturas e regras essenciais.

VOCABULÁRIO

Palavras organizadas por temas do cotidiano.

CONVERSAÇÃO

Perguntas, respostas e estruturas usadas em conversas.

PHRASAL VERBS

Phrasal verbs importantes com significado e exemplos.

EXPRESSÕES

Expressões comuns encontradas em inglês real.

INGLÊS PARA VIAGENS

Aeroporto, hotel, restaurante, compras e situações do dia a dia.

PRONÚNCIA

Conteúdos para facilitar a compreensão da pronúncia.

Do básico ao avançado.

A1 → A2 → B1 → B2 → C1 → C2

“Comece pelo seu nível e avance no seu ritmo.”

Subheadline:

“Os conteúdos são organizados para facilitar tanto quem está começando quanto quem já estuda inglês e quer revisar.”

Criar uma timeline horizontal elegante.

-------------------------------------

7. COMO USAR

-------------------------------------

Headline:

“Aprenda. Consulte. Revise.”

Criar 3 passos:

1.

ESCOLHA O CONTEÚDO

Abra o mapa do assunto que deseja estudar.

2.

APRENDA VISUALMENTE

Veja regras, exemplos e informações organizadas em uma única página.

3.

REVISE QUANDO QUISER

Volte aos mapas sempre que precisar reforçar algum conteúdo.

Adicionar ilustrações ou ícones discretos.

-------------------------------------

8. CARROSSEL — COMO O MATERIAL É USADO

-------------------------------------

ESSA SEÇÃO TAMBÉM É MUITO IMPORTANTE.

Criar um segundo carrossel.

Headline:

“Estude onde você estiver”

O carrossel deve mostrar cards verticais com fotografias/mockups do produto sendo usado:

- mapa aberto em tablet

- mapa no celular

- mapas impressos na mesa

- estudante usando notebook

- material impresso em parede/caderno

- pessoa estudando em uma cafeteria

- estudante revisando antes de uma prova

Pode existir uma pequena frase abaixo de cada imagem.

Exemplos:

“Use diretamente no tablet.”

“Revise pelo celular.”

“Imprima seus mapas favoritos.”

“Tenha seus principais conteúdos sempre por perto.”

IMPORTANTE:

Não criar depoimentos falsos com nomes, fotos ou resultados inventados.

Essa seção deve demonstrar USO DO PRODUTO, não inventar prova social.
